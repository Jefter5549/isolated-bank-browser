# Isolated Bank Browser for iOS (Custom CA)

Изолированный легковесный веб-клиент на базе `WKWebView` со встроенными доверенными сертификатами **Минцифры РФ (Russian Trusted Root & Sub CA)**.

---

### Архитектура и безопасность

1. **Полная изоляция от системы:** Сертификаты Минцифры встроены напрямую в бандл приложения (`.der`). Оценка доверия TLS (`SecTrustSetAnchorCertificates`) происходит **строго внутри сессии приложения**.
2. **Нулевой системный след:** В системное хранилище iOS Keychain и профили конфигурации устройства **не устанавливается никаких корневых сертификатов**. Safari, системные службы и другие приложения остаются в стандартной безопасной среде.
   TLS-проверка требует корректной цепочки, срока действия, назначения сертификата и совпадения имени сервера. Встроенные Root и Sub CA дополняют системные якоря доверия приложения. Доверия по тексту названия сертификата и fallback на Basic X.509 нет; при ошибке соединение отменяется.
   Исключения App Transport Security отключены. Переходы на HTTP, в том числе через редиректы и всплывающие окна, блокируются. Сайт с некорректным сертификатом или устаревшими параметрами TLS может перестать открываться — обходить проверку для него нельзя.
3. **Нативная поддержка интеграций:**
   * Камера для сканирования QR-кодов СБП (разрешения `requestMediaCapturePermissionFor`).
   * Обработка всплывающих окон, 2FA и подтверждений платежей.
   * Pull-to-refresh, индикатор прогресса, история переходов (Back/Forward).
   * Меню быстрого перехода к веб-банкам (КУБ, ВТБ, Сбер, ГПБ, Альфа-Банк, Госуслуги).

### Сборка и установка через GitHub Actions

1. При каждом коммите в ветку `master` GitHub Actions автоматически собирает `.ipa` файл (`macos-14` / Xcode 15/16).
2. Скачайте собранный артефакт `IsolatedBrowser-unsigned-ipa` со страницы вкладки **Actions** репозитория.
3. Подпишите IPA вашим сертификатом разработчика через любую утилиту:
   * **Sideloadly** (macOS / Windows)
   * **AltStore / Scarlet / TrollStore**
   * **iOS App Signer** (macOS)
   * **Xcode** (`xcodebuild` / Run on Device)

### Локальная сборка на Mac (при наличии Xcode)

```bash
# Установка xcodegen
brew install xcodegen

# Генерация проекта Xcode
xcodegen generate

# Открытие проекта
open IsolatedBrowser.xcodeproj
```

### Регрессионные проверки TLS

На macOS с Xcode CLI, OpenSSL 3 и Python 3:

```bash
# Локальные тестовые CA/сертификаты; системное хранилище не меняется.
OPENSSL_BIN="$(brew --prefix openssl@3)/bin/openssl" bash scripts/test-tls.sh

# Дополнительно: реальный публичный HTTPS через тот же обработчик challenge.
OPENSSL_BIN="$(brew --prefix openssl@3)/bin/openssl" bash scripts/test-tls.sh --live
```

Скрипт компилирует исходный production-код проверки доверия с тестовой обвязкой, создаёт временные ключи и удаляет их после завершения. Проверяются корректная цепочка, неверное имя, сроки действия, назначение, повреждённая подпись, поддельные названия CA, отмена challenge и запрет HTTP. Локальные тесты включены в CI перед сборкой IPA.

Эти проверки Apple Security на macOS не заменяют проверку WKWebView на iOS: перед выпуском нужны реальные публичные и банковские HTTPS-страницы, отказ для неверных сертификатов, HTTP-редиректов и смешанного контента. Вход, 2FA и платежи проверяются отдельно.
